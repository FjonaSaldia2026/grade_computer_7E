PSHS Grade Calculator
This program computes a PSHS student's grades for each quarter and the final grade. It uses the scores from Written Works, Performance Tasks, and Quarterly Assessment.
How the Program Works

First, it computes the tentative grade:

Final Grade = (WW × 30%) + (PT × 50%) + (QA × 20%)

Then it computes the quarters:

Q1 = Tentative Q1
Q2 = (Q1 + 2 × Tentative Q2) ÷ 3
Q3 = (Q2 + 2 × Tentative Q3) ÷ 3
Q4 = (Q3 + 2 × Tentative Q4) ÷ 3

The final grade is Q4.
